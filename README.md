# Alexa AI Email Assistant & Query Workflow

**Author:** [BadyMejia](https://github.com/BadyMejia)
**License:** PolyForm Noncommercial 1.0.0

## Description
Voice-activated email management workflow for Amazon Alexa, powered by LangChain, Groq LLMs, Tavily Search, and PostgreSQL.

## Requirements
* PostgreSQL credentials (table setup required)
* Groq API credentials
* Tavily API credentials (optional web search)
* Amazon Alexa Skill configured with webhook endpoint
